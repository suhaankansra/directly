## 2. App Store description

**Short (promotional text, 170 chars)**

> Your messages, your people, and nothing to scroll. Only Inbox opens Instagram straight into your
> DMs and removes the feed, Reels and Explore — watch the reel a friend sent, then stop.

**Long (4000 char limit, use this)**

```
Only Inbox is Instagram with the scrolling removed.

It opens straight into your messages and takes away the feed, Reels and Explore. You keep the parts
you actually use — your conversations, your notifications, profiles you look up on purpose — and lose
the parts that swallow an hour.

WHAT YOU KEEP
• Your DM inbox, threads, notes and message requests
• Sending text, photos, voice notes, stickers and reactions
• Notifications, including Follow Back
• Profiles you search for deliberately
• One reel or post a friend sends you, opened on its own

WHAT'S GONE
• The home feed
• The Reels tab, and the next reel after this one
• Explore, search grids and suggestions
• Stories, unless you turn them back on
• Any link in a conversation that points into the above

HOW IT WORKS
Only Inbox shows you Instagram's own pages in a single, dark-themed view and hides the parts that lead
somewhere endless. When you open a reel a friend sent, it plays and loops; swiping up does nothing;
back returns you to the conversation. If something would take you to the feed, you land in your inbox
instead, with a short note explaining why.

WHAT IT DOES NOT DO
• It does not read, store or send your messages or your password
• It does not have an account system, analytics or a server
• It does not automate anything: no auto-likes, no auto-follows, no automatic messages
• It does not modify your Instagram account in any way

Your session lives where Instagram put it — in this app's own web view or in your browser — exactly as
it would anywhere else. The app ships with a Safari extension so that instagram.com behaves the same
way in Safari.

Only Inbox is an independent project. It is not affiliated with, endorsed by or sponsored by Instagram
or Meta. Instagram is a trademark of Meta Platforms, Inc.
```

## 3. App Privacy ("nutrition label")

Answer: **Data Not Collected.** Every category — contact info, identifiers, usage, diagnostics,
purchases, location, contacts, user content — is "not collected", because there is no server and no
analytics SDK. Nothing is linked to the user; nothing is used for tracking.

The one nuance to declare honestly if a reviewer asks: the app stores settings on the device. That is
not "collection" under Apple's definition (not transmitted off-device).

## 5. Safari Web Extension (iOS + macOS)

```bash
pnpm build:extension                                  # produces dist/chrome
xcrun safari-web-extension-converter apps/extension/dist/chrome \
  --project-location apps/ios/safari-extension \
  --app-name "Only Inbox" --bundle-identifier com.onlyinbox.safari
```

- iOS: the converter emits an Xcode project containing an app + extension target. Move the extension
  target into the iOS app (or set up a workspace), then add an onboarding screen that says:
  *Settings → Safari → Extensions → Only Inbox → Allow on instagram.com.*
- macOS: run the generated project once, then **Safari → Settings → Extensions → Only Inbox → Allow**.
- The conversion requires Xcode and a Mac; there is no cloud-only path.

## 6. Chrome Web Store listing

**Single purpose statement (required, verbatim field)**

> Only Inbox reduces Instagram's website to its direct-message inbox: it hides the feed, Reels and
> Explore, and it stops a reel opened from a conversation from scrolling to the next one.

**Permission justification**

| Permission | Justification |
|---|---|
| `host: instagram.com` | The extension only functions on Instagram's website; it reads no other site. |
| `storage` | Stores six on/off switches locally. No other data. |
| `webNavigation` | Detects a full page load to a blocked route (for example a redirect after login) so it can be sent to the inbox before it renders. |
| `tabs` | Redirects a blocked tab to the inbox. Consider narrowing to `tabs.update` with no permission before submitting. |

**Remote code declaration:** "The extension does not use remote code. An optional selector list is
plain JSON data; it cannot execute."

**Data usage:** no user data collected; no data sold; no data used for purposes unrelated to the
extension's single purpose.

with the next-reel chevron hidden, and the settings popup.
