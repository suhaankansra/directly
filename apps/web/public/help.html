Help & install

Native APK and iOS builds are available from the rolling GitHub release. The iOS build is unsigned and needs signing with your Apple development team. Browser extensions can be built from source. These downloads predate the current five-tab source update.

Chrome, Edge, Brave, Arc

Loads as an unpacked extension. It survives restarts; Chrome may ask once to confirm.

  1. Download or clone this project, install pnpm, then run pnpm install and pnpm build.
  2. Open chrome://extensions (or edge://extensions, brave://extensions).
  3. Turn on Developer mode.
  4. Choose Load unpacked and pick apps/extension/dist/chrome.
  5. Open instagram.com. The extension routes supported pages to your inbox.

The extension uses storage for settings and session data, and webNavigation to redirect blocked routes. It runs on Instagram pages only.

Firefox (desktop)

  1. Run pnpm build, then open about:debugging#/runtime/this-firefox.
  2. Choose Load Temporary Add-on and select apps/extension/dist/firefox/manifest.json.
  3. Temporary add-ons are removed when Firefox quits; the signed build will be permanent.

iPhone

  1. Download the unsigned IPA from the rolling release.
  2. Sign it with your own Apple development team using Xcode or the project signing instructions.
  3. Install the signed app on your device and open Directly. The current release build is older than the five-tab source update.

For a development build, follow the repository's ship preparation guide. Expo Go does not include the native modules this app uses.

Android

  1. Download directly-main.apk from the rolling release.
  2. Open the APK on your device and allow installation for the app you use to open it, if Android asks.
  3. Launch Directly and sign in to Instagram in its web view.

The APK is a prior release. The current source includes five-tab navigation and Focus controls not present in that download.

Safari on macOS

  1. Build the Chrome target: pnpm build:extension.
  2. Convert it: xcrun safari-web-extension-converter apps/extension/dist/chrome.
  3. Open the generated Xcode project, run it once, then enable the extension in Safari → Settings → Extensions.

If something looks wrong

The feed still appears for a moment

You are seeing Instagram's own first paint before the route guard redirects. Turn on Debug logging in the extension popup to see which rule fired.

A nav item stopped working after an Instagram update

Hiding rules use href, aria-label and role, never class names, but Instagram does change markup. Blocking still holds — only the cosmetic hiding degrades. The selector list can be overridden with a JSON file, so this is fixable without a new release.

I want to be signed out completely

In the current source build: More → Sign out. In the older downloadable build, use Lock → Sign out. In a browser, sign out of Instagram itself.

Does it work in Chrome on Android?

Directly has a native Android app. The desktop browser extension is not for Android mobile browsers.
