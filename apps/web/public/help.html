Help & install

Nothing is on a store yet. Until then every surface can be installed by hand in a couple of minutes, and each section below is the exact sequence.

Chrome, Edge, Brave, Arc

Loads as an unpacked extension. It survives restarts; Chrome may ask once to confirm.

  1. Download or clone this project and run pnpm install, then pnpm build.
  2. Open chrome://extensions (or edge://extensions, brave://extensions).
  3. Turn on Developer mode.
  4. Choose Load unpacked and pick apps/extension/dist/chrome.
  5. Open instagram.com — you should land in your DMs with a four-item bar.

Permissions requested: instagram.com only, plus storage, tabs and webNavigation so a blocked page can be redirected before it renders. No other site is touched.

Firefox (desktop)

  1. Run pnpm build, then open about:debugging#/runtime/this-firefox.
  2. Choose Load Temporary Add-on and select apps/extension/dist/firefox/manifest.json.
  3. Temporary add-ons are removed when Firefox quits; the signed build will be permanent.

iPhone

  1. The app is in App Store review. Once it ships, installing it also installs the Safari extension.
  2. In Settings → Safari → Extensions, turn on Directly, then allow it for instagram.com.
  3. Open Safari, go to instagram.com and sign in. You land in your DMs.

Building it yourself: cd apps/ios && npm install && npx expo run:ios. A development build is required — signing out and the Safari extension need native code that Expo Go cannot provide.

Safari on macOS

  1. Build the Chrome target: pnpm build:extension.
  2. Convert it: xcrun safari-web-extension-converter apps/extension/dist/chrome.
  3. Open the generated Xcode project, run it once, then enable the extension in Safari → Settings → Extensions.

If something looks wrong

The feed still appears for a moment

You are seeing Instagram's own first paint before the route guard redirects. Turn on Debug logging in the extension popup to see which rule fired.

A nav item stopped working after an Instagram update

Hiding rules use href, aria-label and role, never class names, but Instagram does change markup. Blocking still holds — only the cosmetic hiding degrades. The selector list can be overridden with a JSON file, so this is fixable without a new release.

I want to be signed out completely

In the app: Lock → Sign out. In a browser: sign out of Instagram itself, or remove the extension's site data. Directly never stores your session.

Does it work in Chrome on Android?

No. Chrome for Android does not support extensions. Safari on iOS and Firefox on Android do; Android browsers are on the roadmap, not in this build.
