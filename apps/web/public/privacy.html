Privacy policy

Last updated 21 November 2026 · This page is the whole policy.

Short version

Directly has no account system, service backend or analytics. It does not read message text, passwords or cookies. It stores settings and, in the iOS app, the signed-in username locally so the Profile tab can open the right account.

What the app and extension can see

Directly works by changing the Instagram page you are already looking at. The iOS and Android apps display instagram.com in a single web view; in a browser the extension runs only on instagram.com. Because of that it can see the page, in the same way the page is visible to you.

The page logic checks routes, applies interface cleanup, and reads limited page details needed for controls: the signed-in username from a profile link, story tray usernames, and the unread count when Instagram exposes one. It does not inspect message contents.

What it never does

  • It never reads, stores or transmits your password or your cookies.
  • It does not send message, profile or thread content to a Directly service or third party. Directly has no service backend.
  • It never automates activity: no auto-likes, auto-follows, scheduled posts or mass messages.
  • It never injects remote code. An optional selector list is plain data (JSON) and cannot execute.
  • It contains no advertising or analytics service. The native apps use platform libraries for storage, notifications and the web view.

What is stored, and where

Settings, alert preferences and the remembered username are stored locally by the native app. The extension stores settings and session-scoped story selection data in browser extension storage. Unread counts and diagnostic logs are held in memory while the app is running. Removing the app or extension removes its local data.

Your Instagram session remains in the browser or app web view's cookie store. Directly does not read or copy cookies. Instagram receives the requests needed to display and use Instagram, as it would in a browser.

This website

No cookies, no analytics, no fonts loaded from a third party and no third-party scripts. It is static HTML, CSS and one small local script. Your browser tells the script its user agent so that the right install option can be highlighted; that value stays in your browser.

Children

Directly is not directed at children under 13, and it cannot be used without an Instagram account, which has its own minimum age.

Changes

If this policy changes, the date at the top changes with it. Directly has no service backend holding app data to migrate or delete.

Contact

Open an issue at github.com/suhaankansra/directly — it is the same place bugs are reported, and it is the only inbox this project reads.
