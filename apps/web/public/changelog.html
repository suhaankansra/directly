Changelog

What changed, and when.

Newest first. Nothing here is on a store yet, so every entry describes something you can build and run yourself today — and each one says what has actually been tested.

0.1.0 — renamed to Directly

2 November 2026
  • The product is now Directly, everywhere: app name, bundle id, extension, this site and the code itself.
  • The iOS app builds and launches in the simulator for the first time.
  • One internal namespace, di-, replaces the placeholder one in attributes, CSS and the page↔app protocol.
  • New pages here: this changelog and the features page.

Still unproven: whether Instagram permits a sign-in inside the app's own web view, and the selector list has not yet been checked against a signed-in account.

0.0.1 — first working build

1 November 2026
  • Shared core for routing, the one-reel lock, page cleanup and the four-item navigation, with unit tests.
  • Manifest V3 extension for Chrome, Edge, Brave and Arc, plus a Firefox build.
  • Expo app for iPhone with a native four-tab bar and a Lock screen for the switches.
  • An offline fixture that mimics Instagram's mobile layout, so blocking can be demonstrated without an account.
  • Blocking verified in a real browser against that fixture: feed, Explore and a stray reel redirect; a reel from a DM pins and loops.
